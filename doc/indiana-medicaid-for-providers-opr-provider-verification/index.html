OPR Provider Verification Indiana Medicaid Providers Provider References OPR Provider Verification Indiana Health Coverage Programs (IHCP) providers should verify enrollment of the ordering, prescribing or referring (OPR) provider before services or supplies are rendered. Reimbursement for services requires that the OPR provider be enrolled with the IHCP. The OPR Search Tool is a comprehensive search tool that includes OPR-only and other IHCP-enrolled providers. Providers rendering services should access this tool to make the necessary verification: Launch the OPR Search Tool
