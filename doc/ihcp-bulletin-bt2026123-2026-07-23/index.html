IHCP bulletin INDIANA HEALTH COVERAGE PROGRAMS BT2026123 This bulletin has been updated. Information about BASC-4 has been updated and resources provided. JULY 23, 2026 IHCP is reinforcing documentation and behavior assessment for ABA therapy treatment plans The Indiana Health Coverage Programs (IHCP) previously provided guidance, in IHCP Bulletin BT2024194, for applied behavior analysis (ABA) therapy providers to include the Behavior Assessment System Children, Parenting Relationship Questionnaire (BASC PRQ) within treatment plans and to include documentation of this assessment. No numerical iteration of the BASC PRQ was established, and BASC-3 PRQ was commonly used and accepted.

BASC will no longer include the PRQ assessment in the fourth edition. Considering the release of BASC-4, both the BASC-3 PRQ and BASC-4 will be accepted until Oct. 1, 2026. After Oct.

1, 2026, only the BASC-4 will be accepted. The public release of BASC-4 is expected to be Aug. 23, 2026. Providers should select the most appropriate version of BASC-4 for their members.

For additional information, please see the following resources: • Behavior Assessment System for Children Brochure • Pearson BASC-4 Resources webpage The IHCP will apply a standardized transition policy for behavior assessment tools used in ABA therapy treatment planning. When updated versions of clinically recognized assessment instruments are released, the IHCP will allow a transition period of six months during which both the prior and updated versions may be used. The six-month transition window will begin the date of the publication release. After the transition period, providers are expected to use the most current version unless otherwise specified by the IHCP.
