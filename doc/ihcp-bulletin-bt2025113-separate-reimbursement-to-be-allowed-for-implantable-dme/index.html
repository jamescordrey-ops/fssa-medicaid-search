IHCP bulletin INDIANA HEALTH COVERAGE PROGRAMS BT2025113 AUGUST 5, 2025 Separate reimbursement to be allowed for implantable DME code L8679 for outpatient surgeries Effective for dates of service (DOS) on or after Sept. 5, 2025, the Indiana Health Coverage Programs (IHCP) will allow separate reimbursement for implantable durable medical equipment (DME) Healthcare Common Procedure Coding System (HCPCS) code L8679 – Implantable neurostimulator, pulse generator, any type when the implantation is performed in an outpatient surgical setting. The device must be billed on a professional claim (CMS- 1500 claim form or electronic equivalent), separate from the institutional outpatient claim for the implantation procedure. This change will ensure alignment with current National Clinical Guidelines (NCGs) for phrenic nerve and spinal cord stimulators.

All fee-for-service (FFS) PA requests for this procedure code should be submitted to the FFS medical prior authorization and utilization management (PA-UM) contractor, Acentra Health. The claim-processing system will be updated. All FFS claims for this procedure code should be submitted to Gainwell Technologies. This code will be added to the Implantable Durable Medical Equipment (DME) Separately Reimbursable in the Outpatient Setting table in Surgical Services Codes, accessible from the Code Sets webpage at in.gov/medicaid/ providers.

For more information Questions about PA criteria for these procedure codes should be directed to Acentra Health Customer Service at 866-725-9991. Questions about billing and reimbursement should be directed to Gainwell Customer Assistance at 800-457-4584 or your Provider Relations consultant. Individual managed care entities (MCEs) establish and publish PA, billing and reimbursement criteria within the managed care delivery system. Questions about managed care PA, billing and reimbursement should be directed to the MCE with which the member is enrolled.
