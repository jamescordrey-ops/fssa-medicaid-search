IHCP bulletin INDIANA HEALTH COVERAGE PROGRAMS BT2026149 SEPTEMBER 8, 2026 IHCP simplifies rendering provider linkage processes The Indiana Health Coverage Programs (IHCP) is completing the IHCP Provider Healthcare Portal (IHCP Portal) system enhancements announced in IHCP Bulletin BT2026101, enabling groups to systematically link rendering providers to their service location when the rendering provider is already enrolled in the IHCP. Effective Sept. 30, 2026, the Rendering Provider Agreement and Attestation Form will no longer be required for the following enrollment transactions on the IHCP Portal: ◼ New group enrollments where all rendering providers being linked to the group are already enrolled in the IHCP ◼ Provider maintenance requests to add existing (currently-enrolled) rendering providers to a group enrollment ◼ Revalidations The Rendering Provider Agreement and Attestation Form will remain required for the following enrollment transactions on the IHCP Portal: ◼ New rendering provider enrollments ◼ Conversions from an ordering, prescribing, referring (OPR) provider enrollment to a rendering provider enrollment For transactions submitted prior to Sept. 30, 2026, the IHCP Portal will continue to require a Rendering Provider Agreement and Attestation Form for each rendering provider linked to the group upon initial enrollment and revalidation, as well as to add an existing rendering provider to the group.

Providers will continue to be able to link multiple rendering providers to a group, as well as individual Rendering providers to multiple service locations through one transaction. Note: Similar changes to IHCP Portal updates described in this bulletin will be made to the corresponding “paper enrollment” processes – for providers that opt to submit printed enrollment forms by mail, rather than using the online portal.
