IHCP bulletin INDIANA HEALTH COVERAGE PROGRAMS BT202579 JUNE 5, 2025 IHCP updates code S0145 to be carved out of managed care Effective immediately, the Indiana Health Coverage Programs (IHCP) announces that Healthcare Common Procedure Coding System (HCPCS) procedure code S0145 will be carved out of managed care. This physician-administered drug procedure code (see Table 1) will be carved out of managed care for all settings (inpatient, outpatient and professional), effective retroactively for dates of service (DOS) on or after June 5, 2023. This code will be separately reimbursable outside the inpatient diagnosis-related group (DRG) and must be billed as fee-for-service (FFS) for all members, including those enrolled in a managed care program. Any claims for this procedure code that were paid to providers by a managed care entity (MCE) for DOS on or after June 5, 2023, will be reprocessed and payments recouped by the MCE.

Providers will then need to submit a new claim to Gainwell for FFS reimbursement of this carved-out drug. Providers can submit the claims to Gainwell within 180 days of this publication date to satisfy timely filing requirements. A copy of this bulletin should be included when submitting claims beyond the standard filing limit. This code will be added to Physician-Administered Drugs Carved Out of Managed Care and Reimbursable Outside of the Inpatient DRG, accessible from the Code Sets webpage at in.gov/medicaid/providers.
