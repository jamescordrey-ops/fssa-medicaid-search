Longitudinal Data Project (LDP) The SNAP Longitudinal Data Project (LDP) was approved by Section 4015 of the Agricultural Improvement Act of 2018 (the 2018 Farm Bill), Longitudinal Data for Research. The LDP allows states to build databases using SNAP information. The databases will help support SNAP research. This site gives states information to learn more about the LDP.

It also gives states instructions on what they need in order to get started, if they want to join.
