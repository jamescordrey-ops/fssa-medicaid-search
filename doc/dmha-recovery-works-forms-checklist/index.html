Checklist of Forms The Recovery Works Application packet consists of several documents that allow the Recovery Works team to approve and designate agencies to provide Recovery Works services throughout the State of Indiana. Once an application is received at the state office, the administrative team will review the application. If the application is incomplete, the provider will receive the application back for correction. A complete Recovery Works application contains the following documents):  Copy of DMHA certification  Documentation on approval from Managed Care Entities on insurance acceptance  W-9  Direct Deposit  Recovery Works Application  DARMHA Provider Registration Form  DARMHA New User Form(s)  WITS Setup Spreadsheet All of these forms can also be found at https://www.in.gov/fssa/dmha/recovery-works/recoveryworksforms/.
