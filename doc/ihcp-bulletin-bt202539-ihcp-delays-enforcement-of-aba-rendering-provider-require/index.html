This bulletin has been updated. See IHCP bulletin IHCP Bulletin BT202596. The enforcement deadline for requiring the rendering provider NPI to align with the procedure code modifier on an ABA therapy services claim is Aug. 1, 2025.

INDIANA HEALTH COVERAGE PROGRAMS BT202539 MARCH 13, 2025 IHCP delays enforcement of ABA rendering provider requirement to July 1, 2025 The Indiana Health Coverage Programs (IHCP) previously announced in IHCP Bulletin BT2024194 that effective April 1, 2025, all applied behavior analysis (ABA) therapy service claims must be billed with the rendering provider National Provider Identifier (NPI) matching the procedure code modifier indicating the level of the ABA therapy provider that rendered the service. The IHCP is delaying the enforcement date to July 1, 2025. All other ABA policy changes will continue as scheduled. Table 1 provides the procedure code modifiers that must be used with the ABA therapy service claims.
