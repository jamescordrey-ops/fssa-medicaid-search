Indiana Medicaid State Plan Indiana Medicaid Providers Provider References Other Provider Resources Indiana Medicaid State Plan The Indiana Medicaid State Plan is an agreement between the state and the federal government describing how the state administers its Medicaid program. The Indiana Medicaid State Plan gives an assurance that Indiana will abide by federal rules and may claim federal matching funds for its program activities. The Indiana Medicaid State Plan sets out groups of individuals to be covered, services to be provided, methodologies for providers to be reimbursed and the administrative activities that are underway in the state.
