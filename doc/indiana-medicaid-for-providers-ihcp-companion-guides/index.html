IHCP Companion Guides Indiana Medicaid Providers Business Transactions Electronic Data Interchange (EDI) Solutions IHCP Companion Guides This page contains Indiana Health Coverage Programs (IHCP) companion guides for Health Insurance Portability and Accountability Act (HIPAA) version 5010 electronic transactions. The guides contain structure and specifications for transactions exchanged directly with Gainwell Technologies (fiscal agent for the IHCP). Providers and vendors developing software for electronic data interchange (EDI) may need to view multiple guides. The IHCP companion guides are updated as needed.

See the Change Summary section within each guide for a history of updates. When a system modification is forthcoming, significant changes are conveyed in advance; see the Upcoming Changes for IHCP Companion Guides section of this page. The IHCP companion guides are intended only to supplement the adopted national electronic data interchange transaction set implementation guides. These implementation guides, published by the Washington Publishing Company, are available through the X12 website .

The IHCP companion guides are never intended to modify, contradict or reinterpret the rules established by the implementation guides. The IHCP is in the process of transitioning from the term "managed care entity (MCE)" to "managed care organization (MCO)." During the course of this transition, both terms may appear in IHCP documentation.
