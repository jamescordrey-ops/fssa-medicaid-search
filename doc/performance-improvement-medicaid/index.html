Performance Improvement Most states participating in the Medicaid Innovation Accelerator Program (IAP) program and functional areas receive performance improvement (i.e. quality improvement) training and technical assistance.

This type of technical assistance focused on assisting participating states in creating and using driver diagrams to help them set goals and to determine the aims and “drivers” of change. In addition, IAP created web-based trainings for Medicaid agencies.
