WIC Electronic Benefits Transfer (EBT) and Management Information Systems (MIS) Resources This page provides information for WIC State agencies and partners on WIC electronic benefit transfer (EBT) and management information systems (MIS).

The documents and resources on this page were developed to ensure consistent standards applicable to WIC EBT and MIS. For information on Handbook 901 and Advance Planning Documents (APDs), visit FNA’ State Systems Office (SSO). FNA Handbook 901 describes policies and procedures state agencies must follow when using use federal funding to acquire, develop, and/or implement systems supporting the operation of FNA programs (including WIC EBT and MIS). Technical DocumentsOperating Rules (OR) and Technical Implementation Guide (TIG) are the technical standards for WIC EBT online purchase messages and file handling processes, utilized by both offline (smart card) and online (magstripe) WIC EBT systems.

These resources are used by all state agencies, authorized WIC vendors, and EBT industry stakeholders.WIC Universal MIS-EBT Interface standardizes functional requirements for the Universal Interface between WIC MIS and EBT systems.Functional Requirements Document (FReD) provides a list of functional requirements that all WIC MIS must include. ANSI Standards for WIC EBT define the interface specifications to enable communication between state agencies, retailers, financial institutions, and technology providers.
