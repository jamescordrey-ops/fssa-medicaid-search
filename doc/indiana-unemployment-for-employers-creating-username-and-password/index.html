Indiana Unemployment for Employers: Creating Username and Password Skip to main content Close Menu Accessing the Employer Self Service (ESS) Website Creating a Username and Password Before an employer can report wages in ESS, they must establish credentials to use ESS. New Indiana Employer Registering via ESS for the first time When registering a new Indiana State Unemployment Tax Account, you will: Go to the ESS Welcome Screen, at uplink.in.gov/ESS Click Register at the top of the page next to Log In. Answer the Questions Is this User ID going to be for a UI Employer or Agent Account? Select Employer Do you already have an existing Indiana DWD account number for the account type selected above?

Select No Enter the Federal Employer Identification Number, F E I N, of the entity that you need to register. If the F E I N entered is not already associated to a valid SUTA account, the next two screens will contain information on successful registration. Click “Register Now” to create a new user account. Create your Username, Password, and your Secret Question/Answer.

You enter your email address. Use an email you have access to. You will complete the user registration. You will receive a verification email.

The link in this email will route back to the login screen where you will complete the business registration process. All fields with an asterisk (*) are required. If you have an error message please see, Browser Issues. Employers that already have an Indiana SUTA Account If the Employer already has an existing account, the employer will need to gain access the existing employer account.

Starting with First Time User or Register on the E S S Welcome screen. The next screen is called “Check Existing UI Account.” To complete this screen: Select employer from the first dropdown, “Is this User ID going to be for a UI Employer or Agent Account?” Select “Yes” under the question “Do you already have an existing Indiana DWD account number for the account type selected above?” Enter the Federal Employer Identification Number, F E I N, of the entity that you need to register. The next screen has the user provide the F E I N, SUTA number and last gross wages reported DWD. To successfully claim the employer account, all three challenge questions must exactly match the information stored in E S S.

If the employer uses a third-party to report wages, the employer may need to contact the third-party to determine the amount of Indiana covered wages posted to the employer’s account. Gross wages are the total Indiana State Unemployment Insurance (SUI) covered (subject) wages that have been posted. Make sure you DO NOT round your Total Gross Wages! Report all wages in dollars AND cents.

DO NOT include dollar signs or commas. EX: If your Total Gross Wages are $25,132.56, report “25132.56” instead of $25,133. Do not use an amount that is going to be reported or that was not successfully submitted. If the employer reported no wages in the most recent quarter, zero (0) is a valid response.

Once the questions are correctly answered, the user will be able to create a user account. Enter all fields with an asterisk (*). If you have an error message please see Browser Issues. Return to Employer Guide Home Equal Opportunity is the Law.
