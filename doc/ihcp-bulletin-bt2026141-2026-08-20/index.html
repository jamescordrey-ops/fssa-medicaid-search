IHCP bulletin INDIANA HEALTH COVERAGE PROGRAMS BT2026141 AUGUST 20, 2026 IHCP announces Gainwell’s migration to EDI+ platform for X12 transaction processing On behalf of the Indiana Health Coverage Programs (IHCP), Gainwell Technologies is initiating a project to transition IHCP electronic data interchange (EDI) X12 translation and compliance-processing services from the current Edifecs platform to Gainwell’s centralized enterprise EDI+ Solution. This migration is part of an ongoing modernization effort designed to improve standardization, supportability, operational efficiency and long-term scalability across the IHCP enterprise. What this migration means for your organization At this time, no action is required from trading partners. The following are not expected to change because of this initiative: ◼ Current file exchange processes ◼ Existing real-time interface URLs ◼ Connectivity methods ◼ X12 transaction formats ◼ Day-to-day submission and receipt of transactions Trading partners should continue to submit and receive transactions using their existing processes.

Trading partners and providers should not notice any changes with the implementation of this project. This implementation is primarily a backend system upgrade and is not expected to require modifications to established trading partner connectivity or transaction structures. Planned deployment The migration to EDI+ will be implemented through a series of planned production deployment increments, with an overall project completion target date of April 30, 2027. The list of deployment increments and the associated transaction types are included in Table 1.

Trading partner engagement As part of this initiative, select trading partners will be invited to participate in transaction-specific testing activities before production implementation. ◼ Managed care organization partners  Managed care organization (MCO) partners may participate in applicable testing cycles across supported transaction sets. ◼ Real-time trading partners  Real-time 270/271 and 276/277 transactions are planned to be implemented simultaneously.  A subset of trading partners will be selected to participate in testing activities. ◼ Batch trading partners  Batch transactions will be deployed according to the incremental schedule outlined above.  A subset of trading partners will be invited to participate in testing for each deployment increment. Additional information This communication is being shared for awareness of the upcoming IHCP modernization effort.

Additional communications will be distributed throughout the project to the trading partners via email and will include: ◼ Testing schedules and participation requirements ◼ Deployment timelines ◼ Readiness activities ◼ Project updates and implementation guidance, as applicable Trading partners selected for testing will receive direct communication with specific instructions and next steps. Questions regarding this initiative may be submitted to the IHCP EDI Services team via email at INXIXTradingPartner@gainwelltechnologies.com or by calling Indiana Medicaid Services at 800-457-4584 and, when prompted, selecting option 3 and then option 1.
