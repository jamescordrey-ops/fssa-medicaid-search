You need to also upload the following documents in your request What do I need to do if I am a current ASAM provider and want to increase my bed numbers and change my ASAM level? You need to complete a new ASAM application.

I had my application returned, what do I do next? You need to login to your account, click applications, select view existing applications, select the application name of the application you want to return to. Once selected, click continue existing application. A box will pop up that asks if you want to proceed to complete your application.

Select “NO” and a block will pop up that shows you want items failed along with any feedback from the reviewer. You will complete the changes then re-submit. Copyright © 2026 State of Indiana - All rights reserved.
