IHCP Provider Reference Modules Indiana Medicaid Providers Provider References Bulletins and Reference Modules IHCP Provider Reference Modules The Indiana Health Coverage Programs (IHCP) provider reference modules are the primary reference for billing and reimbursement guidance for providers conducting business with the IHCP. Modules include instructions for submitting IHCP claims and prior authorization (PA) requests, as well as other related topics. Changes to policies and procedures that occur after the effective date noted for each module are announced in IHCP bulletins .
