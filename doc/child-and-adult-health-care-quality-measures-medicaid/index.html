While historically voluntary, reporting of the Child Core Set and the behavioral health measures on the Adult Core Set became mandatory in 2024 for all states, the District of Columbia, the Commonwealth of Puerto Rico, the U.S Virgin Islands, and Guam. Mandatory Core Set reporting requirements are described in 42 CFR Parts 433, 437, and 457, and the Initial Core Set Mandatory Reporting Guidance State Health Official Letter.Through annual guidance, CMS provides updates to the measures included in the Child and Adult Core Sets and specific annual reporting requirements.2027 Child and Adult Core Sets Updates and Mandatory Reporting Guidance SHO2026 Child and Adult Core Sets Updates and Mandatory Reporting Guidance SHOCore Set Final Rule (published August 2023)Historical Policy Guidance
