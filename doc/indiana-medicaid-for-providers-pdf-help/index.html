PDF Help Indiana Medicaid Providers Provider References Forms PDF Help Having trouble opening linked PDF files? If you receive an “Error 404 – Page not found” when trying to open PDF files, or if the files don't open after clicking the link, please try the following: Upgrade your Adobe Reader to the most recent version, which you download free of charge from the Adobe website . Configure Adobe Reader to open outside the browser. This is a one-time change for the user.

Use the following steps: Open Adobe Reader. From the Edit menu, choose Preferences . On the left panel, click the “Internet” category. Locate and uncheck the box labeled “Display PDF in browser.” Click OK .

Close Adobe Reader. Close any open browser windows and restart the website. Open the PDF link in a new browser window: Right-click the link. From the menu, select "Open Link in New Window." Save the PDF file to your local PC: Right-click the link.

From the menu, select "Save Link As ..." A dialog box opens. Save the file to a directory. After saving the file, open it from the same directory where you saved it. Note: The specific steps and menu options may vary depending on your browser type and version.
