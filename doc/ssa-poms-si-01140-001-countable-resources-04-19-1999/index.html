SSA - POMS: SI 01140.001 - Countable Resources - 04/19/1999 Skip to content Program Operations Manual System (POMS) Effective Dates: 04/19/1999 - Present Previous | Next TN 8 (04-99) SI 01140.001 Countable Resources INTRODUCTION This subchapter contains instructions for the development of resources whose value ordinarily will count toward the SSI limit. Use these instructions only after you have made certain that the property at issue: • is a resource, based on instructions in the SI 01110 and SI 01120 subchapters; and • is not an excluded resource, based on instructions in the SI 01130 and SI 01150 subchapters.
