Skip to main content Close Menu SPD Workshops FSSA The HUB more-hot-topics SPD Workshops The Indiana State Personnel Department is offering virtual workshops for all State of Indiana employees to engage with resources, skills, and strategies presented by INSPD subject matter experts. To review the Learning Objectives and a brief overview of these workshops, visit the workshops link. Please note, the majority of these workshops require the same brief prerequisite: Performance & Goals: Foundations of Effective Evaluation. It can be completed at any time.

To register for a virtual workshop, please visit the class registration page in SuccessFactors Learning or select the class you wish to attend below.
