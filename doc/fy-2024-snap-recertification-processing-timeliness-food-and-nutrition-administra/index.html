FY 2024 SNAP Recertification Processing Timeliness Resource Type Research and Data Program Data Technical Assistance The Food and Nutrition Administration evaluates recertification processing timeliness as part of the quality control (QC) review process. State QC reviewers evaluate timeliness during the state QC case review. Recertification processing timeliness is calculated by dividing the number of SNAP recertification applications approved timely for a given period of time (i.e., day, month, year, etc.) by the total number of recertifications approved within that same time period. A SNAP recertification application is considered processed timely when the household has been certified with access to their benefit allotment by their normal issuance date.

FNA removes client-caused delays when calculating recertification processing timeliness, using only agency-caused delays to monitor state agency compliance with statutory requirements.
