Performance Indicator Technical Assistance Related ResourcesMedicaid & CHIP Eligibility Operations and Enrollment SnapshotMedicaid & CHIP Enrollment Data HighlightsMedicaid MAGI & CHIP Application Processing Time Report (retired) The Centers for Medicare & Medicaid Services (CMS) relies on states to submit monthly data on key processes related to eligibility and enrollment to construct the Performance Indicators monthly reports on state Medicaid and CHIP agency activity.

This page includes resources to assist states with monthly Performance Indicator data submissions to CMS. Resources include a data dictionary describing the Performance Indicators, a list of frequently asked questions (FAQs), training modules describing the Performance Indicator project and how the indicators relate to each other, and a set of instructions for states on how to submit data.Overview of Performance Indicator Project - Introductory information for orienting new staff to the Performance Indicator data collection initiative.Training Modules for Reporting Performance - Information specific to each marketplace type explaining how the indicators relate to one another and how data should be reported for each indicator.Sample Household Document - Instructions for reporting Performance Indicator data for three example households.Performance Indicators Data Dictionary - Defines the terminology used in the Performance Indicators, which has been updated to reflect clarifications provided to states through webinars, technical clarification documents ("Qs and As") and technical assistance provided to states via email and conference calls.FAQs about Performance Indicators - Compiles state questions and CMS answers regarding the Medicaid and CHIP Performance Indicators. New questions and answers are identified by the symbol, " * ".List of Performance Indicators and Sub-Indicators - Lists all of the Medicaid and CHIP Eligibility and Enrollment Performance Indicators and Sub-Indicators.Indicator Name Crosswalk - Crosswalks the Performance Indicator names against the technical field name in the State Data Information System (SDIS), also known as Socrata or the PI reporting portal.Performance Indicator Report Submission - Instructions for states on how to upload, update, and submit Performance Indicator data to CMS via the State Data Information System (SDIS), also known as Socrata or the PI reporting portal.https://sdis.medicaid.gov/user/login - Link for state reportingIf you are staff in a state that is responsible for submitting Performance Indicator data and you have questions, please contact PerformanceindicatorsTA@cms.hhs.gov.
