Common Compliance Errors Detected by the IHCP Translator Indiana Medicaid Providers Business Transactions Electronic Data Interchange (EDI) Solutions Common Compliance Errors Detected by the IHCP Translator Indiana Health Coverage Programs (IHCP) transactions can be rejected for compliance errors in the Interchange Control Header – ISA envelope. The TA1 Interchange Acknowledgement response file is generated and posted for the trading partner if there are envelope errors. The ISA must be received exactly as expected. The IHCP companion guides contain the valid ISA envelope values.

The following are common rejections resulting from invalid data in the ISA envelope: Error code 006 – Invalid Interchange Sender ID: ISA06 and GS02 contain a test submitter ID, when data sent is production data. ISA06 and GS02 contain the login ID instead of the trading partner ID. ISA06 and GS02 contain invalid submitter ID. Error code 008 – Invalid Interchange Receiver ID: ISA08 and GS03 do not contain IHCP.

Error code 020 – Invalid Test Indicator Value: ISA15 is not a valid value. P should be sent on Production files, and T should be sent for Test files. Error code 024 – Invalid Interchange Content: File is not X12. Sending proprietary format for non-IHCP data.

Error code 025 – Duplicate Interchange Control Number: ISA13 is a duplicate of a previously submitted interchange control number. A complete list of TA1 error codes and descriptions can be found in the TA1 and 999 Acknowledgements Companion Guide .
