IHCP bulletin INDIANA HEALTH COVERAGE PROGRAMS BT2025145 OCTOBER 9, 2025 Corrections announced to previously published Family Planning Eligibility Program coverage Indiana Health Coverage Programs (IHCP) Bulletin BT2025135 announced upcoming coverage changes for the Family Planning Eligibility program and the corresponding presumptive eligibility (PE) plan, PE – Family Planning Services. This bulletin corrects and replaces BT2025135. For dates of service (DOS) on or after Oct. 30, 2025, only the Current Procedural Terminology (CPT®1) procedure codes listed in Table 1 will be removed from coverage for Family Planning Eligibility Program and PE – Family Planning Services members.

The CPT procedure codes listed in Table 2 and the International Classification of Diseases (ICD) diagnosis code listed in Table 3 will continue to be covered under both programs for DOS on or after Oct. 30, 2025. 30, 2025 (these codes were included in BT2025135 in error) Procedure code 71045 87101 Code description Radiologic examination, chest; single view Culture, fungi (mold or yeast) isolation, with presumptive identification of isolates; skin, hair, or nail Table 3 – Diagnosis code that will remain allowable for the Family Planning Eligibility Program for DOS on or after Oct. 30, 2025 (this code was included in BT2025135 in error) Procedure code Z302 Code description Encounter for sterilization 1 CPT copyright 2025 American Medical Association.
