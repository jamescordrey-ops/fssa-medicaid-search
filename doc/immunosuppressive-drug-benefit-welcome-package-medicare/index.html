Immunosuppressive drug benefit welcome package | Medicare Skip to main content Search Search Search Print this page. Immunosuppressive drug benefit welcome package What is it? This package includes: A letter with information about your Medicare immunosuppressive drug benefit Your new Medicare card When should I get it? About 2 weeks after you sign up for the Medicare immunosuppressive drug benefit.

Who sends it? Medicare What should I do if I get this package? Read the letter carefully because it contains important information, like when you can start using your new Medicare card, and what you should do with your old card. It also tells you what to do if you get other health coverage.
