IHCP bulletin INDIANA HEALTH COVERAGE PROGRAMS BT2025159 NOVEMBER 13, 2025 Five incontinence, ostomy and urological supply codes no longer subject to contracted vendor requirements The Indiana Health Coverage Programs (IHCP) has reviewed the Incontinence, Ostomy and Urological Supplies Available Only Through Contracted Vendors (for Fee-for-Service Members) code table in comparison with the incontinence vendor contracts. As a result of this review, five codes will be removed from the code table, effective immediately retroactive for dates of service (DOS) on or after Jan. 1, 2024. This change applies to fee-for-service (FFS) claims only.

Table 1 – Incontinence, ostomy and urological supply procedure codes no longer subject to contracted vendor requirements for FFS members, effective for DOS on or after Jan. 1, 2024 Procedure code A4360 Code description Disposable external urethral clamp or compression device, with pad and/ or pouch, each A4436 Irrigation supply; sleeve, reusable, per month A4437 Irrigation supply; sleeve, disposable, per month A5056 Ostomy pouch, drainable, with extended wear barrier attached, with filter, (1 piece), each A5057 Ostomy pouch, drainable, with extended wear barrier attached, with built in convexity, with filter, (1 piece), each Updates will be made to the applicable table in Durable and Home Medical Equipment and Supplies Codes, accessible from the Code Sets webpage at in.gov/medicaid/providers. For more information about contracted vendor requirements for select incontinence, ostomy and urological supply codes for FFS members, see the Durable and Home Medical Equipment and Supplies provider reference module.
