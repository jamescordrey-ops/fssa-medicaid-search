Electronic Disability Guide (eDG) Skip to content Social Security Online Disability Programs www.socialsecurity.gov Search Disability Home Electronic Disability Guide (eDG) The Electronic Disability Guide (eDG) is a repository for policy, process and procedure changes for offices processing disability cases as SSA transitions from paper to electronic processing for disability claims. eDG is organized by user component sections. Many sections address disability claims processes for initial claims, reconsiderations, disability hearings and post entitlement activities. DI 805: Electronic Disability Guide (eDG) This chapter contains an overview of the electronic process, the eDib Internet Intake Process, Internet Disability Reports, eView information, and OHA's Case Processing and Management System for disability cases when a paper folder is the official folder. DI 806: Electronic Disability Procedures This chapter contains the electronic disability procedures for the components that process or review disability cases when a paper folder is the official folder.

DI 807: Electronic Disability Guide (eDG) Certified Electronic Process This chapter contains an overview of the certified electronic process, the eDib Internet Intake Process, Internet Disability Reports and eView information for States certified to process disability cases in a fully electronic environment (without a paper folder). DI 808: Electronic Disability Guide (eDG) Procedures for the Certified Electronic Process This chapter contains the certified electronic disability procedures for the components that process or review disability cases in States certified to process cases in a fully electronic environment (without a paper folder).
