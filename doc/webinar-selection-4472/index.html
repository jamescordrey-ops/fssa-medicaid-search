If you are interested in learning about the Ticket to Work program or Work Incentives, you can attend a free Work Incentive Seminar Event (WISE) online webinar. WISE webinars are online events held for people who are age 18 through 64 and receive Social Security Disability benefits. You'll learn about the Ticket to Work Program and available Work Incentives through accessible learning opportunities.

WISE webinars are generally held on the fourth Wednesday of each month. Register below! To attend an online WISE webinar, begin registration by selecting an event below. Please select an event for more information.
