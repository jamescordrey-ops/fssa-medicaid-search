IHCP bulletin INDIANA HEALTH COVERAGE PROGRAMS BT2025147 OCTOBER 21, 2025 IHCP clarifies requests to add taxonomy codes The Indiana Health Coverage Programs (IHCP) has received feedback from providers that experience claim denials as a result of taxonomy code discrepancies on their IHCP provider enrollment profiles. Providers that add a taxonomy code through the Provider Maintenance link on the IHCP Provider Healthcare Portal (IHCP Portal) will be given the date the request is submitted as the effective date for the taxonomy code linkage. If providers need to add a taxonomy code retroactively to their enrollment profile, they need to submit this request using the IHCP Portal Secure Correspondence feature. Providers should select I need help or have a question on my Provider Enrollment on the Secure Correspondence Select Category page.

Providers will need to include all the following information in the request: ◼ IHCP Provider ID for the impacted enrollment ◼ Taxonomy code ◼ Requested effective date of the taxonomy code linkage For more information or assistance, reach out to your Provider Relations consultant.
