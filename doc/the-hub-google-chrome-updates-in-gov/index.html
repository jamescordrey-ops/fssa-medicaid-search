Skip to main content Close Menu Google Chrome Updates FSSA The HUB more-hot-topics Google Chrome Updates Google Chrome Security Update March 13 As part of IOT’s ongoing commitment to security and risk management, we will be enhancing security settings on Google Chrome to strengthen browser security and protect enterprise systems beginning in your agency on Friday, March 13, 2026.Specific Changes to Note Google Password Manager will be disabled. Users will no longer be able to use a Google profile to save passwords or other login info on the browser. IOT recommends installing the Keeper Password Manager for secure credential storage and management. Instructions for Keeper are available on IOT’s website at in.gov/iot/statewide-training-resources/ While bookmarks won't necessarily be removed as a part of this security update, it is important to remember that bookmarks are tied to individual Google Chrome profiles.

If users have multiple profiles or create new ones, those bookmarks may get lost. Browser extension usage will be limited to extensions approved by IOT. The Keeper Password Manager Extension is already approved and may continue to be used in Chrome. What to Expect Changes will apply automatically on your scheduled date.

You do not need to take any action. You may notice stricter security controls, including limited extension usage and updated browser policies. Need Help? If you encounter problems after the update, please contact your agency’s IT support or submit a ticket through the Help Desk at (317) 234-HELP (4357) or toll free at (800) 382-1095.Thank you for your cooperation in keeping our systems secure.
