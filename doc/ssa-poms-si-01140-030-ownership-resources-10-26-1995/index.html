SSA - POMS: SI 01140.030 - Ownership - Resources - 10/26/1995 Skip to content Program Operations Manual System (POMS) Effective Dates: 10/26/1995 - Present Previous | Next TN 3 (07-90) SI 01140.030 Ownership - Resources A. Operating policy — liquid resources 1. Assumption For presumably liquid resources (SI 01110.305), assume that the person whose name is shown as owner owns the entire resource. If more than one owner is shown, assume that each has an equal ownership interest.

2. Exceptions: Checking/Savings Accounts and Time Deposits See SI 01140.200 and SI 01140.205 for checking and savings accounts. See SI 01140.210 for time deposits. B.

Operating policy — nonliquid resources For presumably nonliquid resources (SI 01110.310), assume, absent some indication to the contrary, that an individual's allegation of sole ownership is correct.
