INDIANA HEALTH COVERAGE PROGRAMS BT2025135 SEPTEMBER 30, 2025 IHCP updates coverage for the Family Planning Eligibility Program effective Oct. 30, 2025 Effective Oct. 30, 2025, the Indiana Health Coverage Programs (IHCP) is updating the Family Planning Eligibility Program code set to remove coverage for certain codes.

For dates of service (DOS) on or after Oct. 30, 2025, claims for the Current Procedural Terminology (CPT®1) procedure codes listed in Table 1, or with the diagnosis code listed in Table 2, will be noncovered for members enrolled in the Family Planning Eligibility Program or in the corresponding presumptive eligibility (PE) plan, PE – Family Planning Services. Updates will be made to Family Planning Eligibility Program Codes, accessible from the Code Sets webpage at in.gov/medicaid/providers. For more information about these limited-benefit plans, see the following modules: Family Planning Eligibility Program, Presumptive Eligibility and Member Eligibility and Benefit Coverage.

Table 1 – Procedure codes no longer covered for the Family Planning Eligibility Program, effective for DOS on or after Oct. 30, 2025 Procedure Code description code 53230 Excision of urethral diverticulum (separate procedure); female 53260 Excision or fulguration; urethral polyp(s), distal urethra 71045 Radiologic examination, chest; single view 87101 Culture, fungi (mold or yeast) isolation, with presumptive identification of isolates; skin, hair, or nail Table 2 – ICD-10 diagnosis code no longer allowable for the Family Planning Eligibility Program, effective for DOS on or after Oct. 30, 2025 Diagnosis Code description code Z302 Encounter for sterilization 1 CPT copyright 2025 American Medical Association.
